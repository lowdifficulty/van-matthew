# Van & Matthew

Original athletic and lifestyle house. Quiet luxury, considered performance.

This is a new brand site — not a clone of any existing sports company. All names, copy, marks, and visuals are original.

## Local

**http://localhost:3002**

Port `3002` is reserved so this house does not collide with other local brands on `3000` / `3001`.

```bash
npm install
npm run dev
```

Production-style local serve after a build:

```bash
npm run build
npm start
```

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Client-side cart (React context + `localStorage`)

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Dev server on port **3002** |
| `npm run build` | Production build |
| `npm start` | Serve the build on port **3002** |
| `npm run lint` | ESLint |

**Van & Matthew** is a dual-founder athletic house. Product names, collections, and story are original to this project.
